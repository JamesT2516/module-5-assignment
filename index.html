About Me

Hi, I’m James Taljaard. I’m currently working through a Front-end Web Development course and using this portfolio to put what I learn into practice.

I started with HTML and learned how to give webpages clear structure. I then moved into CSS, responsive design, Flexbox, and CSS Grid to improve how websites look and adapt across different screen sizes.

I am now learning JavaScript and beginning to understand how websites can respond to user actions, work with data, and change content dynamically. Building this portfolio one module at a time is helping me understand how HTML, CSS, and JavaScript work together.

What I Am Learning

Bringing Websites to Life with JavaScript

After learning how to structure webpages with HTML and create responsive layouts with CSS, I am now learning how JavaScript adds behaviour and interactivity to a website.

I am learning how JavaScript can respond to user actions, make decisions, organise data, and interact with the Document Object Model to update content on the page.

Skills I’m Building

  • Creating structured and accessible webpages with semantic HTML5
  • Styling responsive layouts using CSS, Flexbox, Grid, and media queries
  • Using transitions, hover effects, and visible focus states
  • Working with JavaScript variables, constants, functions, and operators
  • Using conditionals, loops, arrays, and objects to work with data
  • Selecting and changing webpage elements using the DOM
  • Using event listeners to respond to user interaction
  • Testing, debugging, validating, and managing projects with Git and GitHub

My Projects

My Front-End Portfolio Website

This portfolio is my ongoing project for the Front-end Web Development course. It started as a simple semantic HTML page and has developed as I have progressed through each module.

I added CSS to improve the colour, typography, spacing, and layout before making the website responsive using a mobile-first approach, media queries, Flexbox, and CSS Grid.

I am now adding JavaScript to introduce behaviour and interactivity. For Module 5, I created an interactive contact message that appears when the page loads and responds to user actions.

As I continue through the course, I’ll keep improving this portfolio and applying the new skills I learn.
